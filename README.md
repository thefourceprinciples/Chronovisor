# Chronovisor v0.3

Open historical reconstruction. Auditable methodology.

Chronovisor is the public research archive and presentation layer for UCMS (Unified Chronovisor Methodology System): a structured approach to AI-assisted historical reconstruction built around explicit evidence classes, adversarial attack, null reconstruction, comparison, classification, provenance, and iterative ledgering.

## Core sequence

EXPAND -> ATTACK -> NULL -> COMPARE -> CLASSIFY -> LEDGER -> ITERATE

## Stewardship principle

**Generate value; don't enclose value.**

The historical record is shared human inheritance. Chronovisor publishes reconstruction and evidence openly; commercial value, where developed, comes from original methodology, software, training, commissioned labor, and crafted artifacts rather than enclosing the past.
